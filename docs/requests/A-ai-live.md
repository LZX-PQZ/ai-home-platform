# A 的变更请求：接通真实需求澄清模型

- 提出角色：A
- 状态：待 D 配置和验收

## 目标

需求澄清页面已经按公共 `ChatResult` 契约接线。当前页面可以展示模拟结果并让业主核对后提交，但真实模型调用由 D 的服务端 LLM 网关负责，A 不修改公共 API、依赖、环境配置或 `src/lib/llm.ts`。

## D 需要确认的实现

1. 在服务端配置真实模型供应商的 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`，并以 `AI_MODE=live` 启用；密钥只能由服务端读取。
2. 真实模型响应继续严格校验为公共 `ChatResult`，缺字段、臆造金额或非法枚举必须返回失败，不降级成模拟成功。
3. 保留现有超时、有限重试和 503/`AI_UNAVAILABLE` 失败语义；模型未配置或不可用时，页面显示“需求助手暂时不可用”，不伪装为实时结果。
4. 用隔离测试或受控供应商响应验证 `meta.source = "live"`、完整草稿、缺失字段和非法 JSON；不得在仓库提交密钥或真实用户内容。

## A 侧验收

- 页面只依赖 `POST /api/demand/chat` 的公共信封，不读取供应商字段。
- `meta.source = "mock"` 时显示“模拟结果”，`live` 时显示“实时结果”。
- 页面不再向业主展示 API 路径、D 角色名、`AI_MODE`、HTTP 状态码或内部错误码。
